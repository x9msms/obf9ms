เรียกใช้ API ตรงๆ (curl / fetch) 
curl -X POST https://obf9ms.vercel.app/api/obfuscate \
  -H 'content-type: application/json' \
  -d '{"code":"print(1+1)"}'
const r = await fetch('/api/obfuscate', {
  method: 'POST',
  headers: { 'content-type': 'application/json' },
  body: JSON.stringify({ code: 'print(1+1)' })
});
const { ok, code: obfuscated } = await r.json();

เพิ่ม "download": true ใน body เพื่อรับเป็นไฟล์ .lua ดิบแทน JSON · เช็คสถานะรันไทม์ได้ที่ GET /api/obfuscate?health=1

ข้อจำกัดที่ควรรู้
  • ขนาด input สูงสุด 512 KB (body limit ของ Vercel คือ 4.5 MB แต่ตั้งเผื่อไว้)
  • เวลา — script เล็กใช้เวลา ~3.5 วินาทีรวม .NET cold start · Vercel Hobby จำกัดที่ 10 วินาที (Pro ถึงจะได้ 60 วิตามที่ตั้งไว้ใน maxDuration)
  • Lua 5.1 รับ local ได้สูงสุด 200 ตัวต่อฟังก์ชัน — เกินนี้จะขึ้น main function has more than 200 local variables ซึ่งเป็นข้อจำกัดของตัวภาษาเอง ไม่ใช่บั๊ก
  • output เป็น VM bytecode ที่ต้องรันบน Lua 5.1 / Luau ที่มี getfenv, bit32 หรือ bit
