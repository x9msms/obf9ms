1. 77fuscator (src/77fuscator-src/)
--------------------------------------------------------------------------
The upstream 77fuscator source archive shipped NO license file. All rights
therefore remain with its author, and the copy in this repository is a
verbatim copy (plus the two documented Linux fixes) of a publicly posted
archive. Do not redistribute it further without the author's permission.

Two files were modified to make the code run on .NET 8 / Linux. Both changes
are described in detail in README.md ("บั๊ก 2 ตัวที่แก้เพื่อให้รันบน Linux ได้"):

  - src/77fuscator-src/77main/Bytecode Library/Bytecode/Opcode.cs
      moved the 7 BITWISE (Luau) opcodes from the middle of the enum to the
      end, so that enum values 0..37 match the stock Lua 5.1 opcode table
      that LuaCompiler-O.dll actually emits.

  - src/77fuscator-src/77main/Bytecode Library/Bytecode/Deserializer.cs
      fixed the inverted endianness test, which reversed every value read on
      little-endian hosts.
